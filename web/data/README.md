# 地域マスターの出典と生成方法

取得日: 2026年9月19日（日本時間）

このディレクトリの CSV は、下記の政府公開データを meshi-archive が加工して作成しました。
自治体名と駅名の確認に外部 API は使用せず、アプリは同梱の CSV を読み込みます。

## 全国の市区町村

`municipalities.csv` は、デジタル庁「アドレス・ベース・レジストリ 全国 市区町村マスター」を加工したものです。

- [データ概要](https://www.digital.go.jp/policies/base_registry_address)
- [公式カタログ](https://dataset.address-br.digital.go.jp/documents/5e130d8117c6426fa1f53a5dbf90cb74)
- [取得元 ZIP](https://data.address-br.digital.go.jp/mt_city/mt_city_all.csv.zip)
- [利用規約](https://www.digital.go.jp/policies/base_registry_address_tos)
- [公式カタログの機械可読フィード](https://dataset.address-br.digital.go.jp/api/feed/dcat-us/1.1.json)

フィードの説明に記載されたデータ更新日時は `2024-03-12T07:52:31.000Z`、
カタログの更新日時は `2025-08-09T17:52:46Z` です。
取得日のデータは1,918行、47都道府県、東京都62区市町村、政令指定都市の行政区171行を含みます。
政令指定都市自体の行とその行政区の行を両方保持しています。都道府県だけの行はありません。
公式マスターに含まれる北方領土の6町村も保持しているため、行数は国内の自治体数と一致しません。

| 列 | 内容 |
| --- | --- |
| `code` | 全国地方公共団体コード。チェック桁を含む6桁の文字列 |
| `prefecture_code` | 都道府県コード。先頭ゼロを保持する2桁の文字列 |
| `prefecture` | 都道府県名 |
| `county` | 郡名。郡がない場合は空欄 |
| `city` | 政令指定都市の行政区の親となる市名。それ以外は空欄 |
| `municipality` | 区・市・町・村の名称。政令指定都市の行政区では区名のみ |

名称の生成は公式 CSV の `ward` がある行では `city` と `ward` を分離し、
それ以外は公式 CSV の `city` を `municipality` としています。
例: `141003,14,神奈川県,,,横浜市`、`141046,14,神奈川県,,横浜市,中区`。

ABR の利用規約は PDL1.0 を基本とし、出典と加工した旨を表示する条件です。
当該データの公式カタログには CC BY 4.0 も記載されています。データの取得元と加工主体を本書に明記しています。

## 東京都の駅

`tokyo_stations.csv` は、国土交通省「国土数値情報（鉄道データ）」2025年度版と
「国土数値情報（行政区域データ）」2026年版の東京都分を meshi-archive が加工して作成しました。

| データ | 基準日 | 公開・更新月 | 出典 |
| --- | --- | --- | --- |
| 鉄道・駅 N02 | 2025年12月31日 | 2026年4月 | [説明・利用条件](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html)、[取得元 ZIP](https://nlftp.mlit.go.jp/ksj/gml/data/N02/N02-25/N02-25_GML.zip) |
| 東京都行政区域 N03 | 2026年1月1日 | 2026年4月 | [説明・利用条件](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html)、[取得元 ZIP](https://nlftp.mlit.go.jp/ksj/gml/data/N03/N03-2026/N03-20260101_13_GML.zip) |

両データは CC BY 4.0 です。行政区域の原典は国土地理院の地図等で、元ページには測量法に基づく利用上の注意も記載されています。
このリポジトリに収録するのは駅名と自治体の対応表のみで、元の地図・線・区域データは収録しません。

| 列 | 内容 |
| --- | --- |
| `station_name` | N02 の駅名。駅名末尾に一律に「駅」を付ける加工は行わない |
| `municipality_code` | 所属する東京の区市町村の6桁コード |
| `source_station_id` | 対応する N02 の駅コード。同名・同自治体の複数路線は `;` 区切りで保持 |

駅の所属は N02 の駅を表す線と N03 の行政区域との**長さを持つ交差**から求めます。
点で接するだけの場合は所属に含めません。最近傍の自治体や推測した住所への置き換えは行いません。
同名駅・同自治体の路線をまとめ、685組（651駅名、50区市町）を収録しています。
境界をまたぐ33駅名には複数自治体を保持します。例: 新宿は新宿区・渋谷区、三鷹は武蔵野市・三鷹市です。

N03 が自治体外の「所属未定地」としている `13000` は対応先から除外しています。
元データの行政境界には暫定境界もあり、測量精度を超える所属の断定には使用できません。
駅の線の所在と駅の郵便住所は一致しない場合があります。この表は駅周辺の街の範囲を定義するものではありません。
「街」エリアは別途管理し、店舗の住所に基づく市区町村と組み合わせて扱います。

武蔵村山市・日の出町・檜原村および島しょ9自治体は、本データに該当する旅客鉄道・軌道の駅がありません。
これらも全国市区町村マスターには収録しています。索道など N02 の対象外の交通施設は含みません。
N02 の駅コードは当該版の出典確認用であり、年度をまたぐアプリの恒久 ID には使用しません。

## 再生成

生成スクリプトは `scripts/build_region_master.py` です。
通常のアプリ依存関係に加え、生成時だけ Shapely 2.1.2 が必要です。
アプリの実行に Shapely は不要です。

```powershell
python -m pip install --target .tmp_geo_sources/python_packages shapely==2.1.2
$env:PYTHONPATH = (Resolve-Path .tmp_geo_sources/python_packages).Path
python scripts/build_region_master.py --source-dir .tmp_geo_sources --download
```

元の ZIP が取得済みの場合は `--download` を外すと、ネットワーク通信なしで再生成できます。
元ファイルのハッシュが上表と異なる場合は処理を停止します。
データ更新時は元ファイル・出典日・差分を確認し、スクリプトのハッシュと本書を更新してから再生成してください。
